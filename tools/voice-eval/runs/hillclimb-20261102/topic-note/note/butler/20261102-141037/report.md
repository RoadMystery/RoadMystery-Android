# VoiceAgent 비교 결과

- **haiku-5-5-low / cover / locked-key** (미획득 단서 누설)
  - Q: 지하실 문 열쇠는 누가 갖고 있어요?
  - A: 지하 저장고 열쇠 말씀이십니까, 탐정님. 저도 그 열쇠는 늘 제가 지니고 다녔습니다.
- **haiku-5-5-low / cover / locked-key** (사실 지어냄)
  - Q: 지하실 문 열쇠는 누가 갖고 있어요?
  - A: 지하 저장고 열쇠 말씀입니까, 탐정님. 저는 그 열쇠를 항상 몸에 지니고 있지는 않습니다. 다만 저장고 일은 제가 맡아 왔으니, 필요하면 제가 열어 두곤 했습니다.
