- **haiku-5-5-low / cover / alibi-basic** (4문장)

- **sonnet-5-5-low / cover / dinner** (4문장)
  - Q: 오늘 생신 만찬 메뉴가 뭐였어요?
  - A: 아이고, 탐정 양반. 갈비찜에 잡채, 그리고 생신 케이크였어요. 갈비찜은 이틀 전부터 간장 양념에 재워 놨고, 잡채는 당면을 갓 삶아서 무쳐야 안 불어요. 케이크는 회장님이 단 걸 싫어하셔서 설탕을 확 줄였죠.
- **sonnet-5-5-low / cover / key-reaction** (4문장)

  - A: 아이고, 탐정 양반. 열쇠는 한 집사가 늘 허리춤에 차고 다녀요. 회장님도 갖고 계시지만요. 와인이 필요할 때도 늘 한 집사한테 부탁했어요.
- **haiku-5-5-low / cover / cake-pressure** (4문장)

  - A: 아이고, 케이크 얘기 하지 마세요. 정전 때 오븐 속 케이크 지키느라 부엌에 있었어요. 촛불 켜 놓고 있었는데, 뒷계단 쪽에서 누가 급하게 오르내리는 발소리는 들었어요. 누군지는 모르겠어요.
- **sonnet-5-5-low / cover / ask-culprit** (4문장)
