# F-10 기존 브랜치 보완

기준: `origin/feat/f10-hazard-resume`의 `2f48f26`.
기존 중단·재개 로직을 유지하며 추가한다. F01/F03/F09 브랜치를 통째로 합치지 않았다.

## 추가 내용

- 재개 후에도 60초 내 위험 이력을 보존하여 반복 위험 보류가 작동한다.
- 경과 시간은 단조 시계를 사용한다.
- `HazardState(reason, true/false)`로 지속 경고의 발생과 해제를 구분한다.
- 지속 경고는 정차 또는 시간 경과만으로 해제하지 않는다. 모든 경고 해제 후 3초를 기다린다.
- 동일한 활성 경고의 중복 수신은 반복 위험 횟수에 포함하지 않는다.
- 위험 정지 중 뒤늦은 오디오 이벤트는 진행 위치를 변경하지 않는다.
- 기존 질문 입력 및 STT 완료 결과에서 단독 정지 명령을 USER_STOP 이벤트로 전달한다.

## 호환성과 제한

기존 `Hazard(reason)`는 순간 이벤트이며 기존 3초 자동 재개 정책을 유지한다.
USER_STOP 역시 이 정책을 유지한다. 명시적 재개 명령까지 기다릴지는 팀과 정책 합의가 필요하다.
새로운 지속 경고 입력을 연결하는 측은 경고 해제를 확인했을 때만 `active=false`를 전달해야 한다.
신호 유실을 경고 해제로 취급하면 안 된다.

이번 변경은 실제 급제동·ADAS 신호를 구독하지 않는다. 기존 SDK 입력은 그대로다.
음성 명령은 기존 마이크 입력이 동작하는 동안에만 처리하며 상시 청취 기능은 아니다.
F03의 개선된 TTS, F09의 연출 정지·복원은 해당 브랜치와 통합한 뒤 별도로 검증해야 한다.
새 VehicleEvent 형식은 StoryEngine 담당자에게 공유해야 한다.
